# Composite

Nutrition, training and body composition in one place: an Expo (React Native) iPhone app with a Supabase backend.

## Documentation

The docs follow the [Diátaxis](https://diataxis.fr/) framework. Each page is one of four types. Pick the one that matches what you need right now:

| I want to… | Go to |
|---|---|
| **Learn** by getting Composite running for the first time | [Tutorials](docs/tutorials/) |
| **Do** a specific task (deploy, build, add something) | [How-to guides](docs/how-to/) |
| **Look up** a fact (tables, env vars, data types, files) | [Reference](docs/reference/) |
| **Understand** why it's built this way | [Explanation](docs/explanation/) |
